Layer7 학기말 프로젝트 · 2인 팀 · 기획 & 개발 담당

pwnable(시스템 해킹) 문제를 풀 때마다 비슷한 익스플로잇 코드를 반복해서 작성해야 하는 불편함을 줄이기 위해 만든 익스플로잇 코드 자동 작성 보조 도구입니다. 사용자가 분석한 오프셋만 입력하면 pwntools 기반 공격 코드의 기본 골격을 자동으로 만들어 줍니다.

주요 기능

  • ELF 바이너리 헤더를 직접 파싱해 보호기법(Canary·NX·PIE·RELRO)을 자동 판별
  • get_shell·system 등 공격에 쓰이는 타깃 심볼과 주소를 자동 탐색
  • 분석 결과로 pwntools 익스플로잇 코드(ex.py) 골격을 자동 생성
  • 외부 라이브러리 없이 순수 파이썬으로 바이너리 구조 분석을 구현

배운 점

자동화 도구를 직접 만들어 보며 ELF 파일 구조와 메모리 보호기법의 동작 원리를 깊이 이해하게 되었고, 도구가 대신해 줄 수 없는 ‘분석하고 논리를 세우는 힘’이 중요하다는 것을 느꼈습니다.

Safe Way Map

창의아이디어 경진대회 · 2인 팀 · LLM 기능 개발 & 발표 담당

‘밤늦게 어두운 골목을 지날 때 느끼는 불안’에서 출발한 안심 경로 추천 앱입니다. 공공데이터(경찰서·가로등 위치)와 시민들이 남긴 안전도 평가를 함께 활용해, 목적지까지 가장 안전한 길을 안내합니다.

주요 기능

  • 안심 경로 추천 — 목적지를 입력하면 안심 점수가 가장 높은 경로를 안내
  • 골목·도로 안전도 평가 — 실제 이동한 길을 1~5점으로 평가해 데이터를 함께 만듦
  • LLM 기반 위험도 분석 — 사용자 평가와 CCTV·경찰서·가로등 데이터를 LLM이 분석해 가장 안전한 길을 선정

차별점 & 나의 역할

위험 지점을 지도에 ‘표시’만 하는 기존 앱과 달리, 안전도를 경로 계산에 직접 반영하는 점이 특징입니다. 저는 LLM 기반 위험도 분석 기능 개발과 발표를 맡았습니다.

KBO 경기 일정 뷰어

개인 프로젝트 · Python

보고 싶은 야구 경기를 편하게 확인하려고 만든 데스크톱 앱입니다. KBO 공식 홈페이지의 월별 경기 일정을 자동으로 수집해 저장하고, 원하는 조건으로 걸러서 볼 수 있습니다.

주요 기능

  • 일정 크롤링 — Selenium·BeautifulSoup으로 월별 경기 일정을 수집해 JSON으로 저장
  • 표 형태 뷰어 — tkinter GUI에서 날짜·시간·상대·구장을 표로 확인
  • 조건 필터 — 날짜·상대 팀·구장·우천취소 여부로 원하는 경기만 골라 보기

배운 점

웹에서 데이터를 수집(크롤링)하고, 저장하고, 화면에 보여 주는 과정을 처음부터 끝까지 직접 만들어 보며 데이터가 흐르는 전체 구조를 이해하게 되었습니다.

앱솔루트 팀 · 3인 · 기획 & 발표 담당

디지털 기기가 익숙하지 않은 디지털 소외 계층도 쉽게 쓸 수 있도록 만든 접근성 앱입니다. ‘탭하면 탁’이라는 이름처럼 크고 단순한 UI로 누구나 어려움 없이 사용할 수 있게 설계했습니다.

세 가지 핵심 기능

  • 간단통화 — 흔들기만 하면 119·112 또는 지정 연락처로 내 위치와 긴급 문자를 전송
  • 셀프계산대 — 무인 키오스크 사용법을 미리 연습하고 안내
  • 지도 — 복잡한 과정 없이 주소만 입력하면 길을 안내

나의 역할

앱인벤터(App Inventor)로 제작했으며, 저는 앱의 기획과 발표를 담당했습니다. ‘모두가 디지털에 평등한 세상’을 목표로 한 프로젝트입니다.
