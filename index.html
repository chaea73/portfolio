Layer7 학기말 프로젝트 · 2인 팀 · 기획 & 개발 담당

pwnable(시스템 해킹) 문제를 풀 때마다 반복되는 익스플로잇 코드 작성을 줄이기 위해 만든 익스플로잇 코드 자동 작성 보조 도구입니다. 분석한 오프셋만 입력하면 pwntools 기반 공격 코드의 기본 골격을 자동으로 만들어 줍니다.

주요 기능

  • ELF 바이너리 헤더를 직접 파싱해 보호기법(Canary·NX·PIE·RELRO) 자동 판별
  • get_shell·system 등 공격 대상 심볼과 주소를 자동 탐색
  • 분석 결과로 pwntools 익스플로잇 코드(ex.py) 골격 자동 생성
  • 외부 라이브러리 없이 순수 파이썬으로 바이너리 구조 분석 구현

배운 점

도구를 직접 만들어 보며 ELF 구조와 메모리 보호기법의 원리를 깊이 이해했고, 자동화가 대신할 수 없는 ‘분석하고 논리를 세우는 힘’의 중요성을 느꼈습니다.

Safe Way Map

창의아이디어 경진대회 · 2인 팀 · LLM 기능 개발 & 발표 담당

‘밤늦게 어두운 골목을 지날 때의 불안’에서 출발한 안심 경로 추천 앱입니다. 공공데이터(경찰서·가로등 위치)와 시민들의 안전도 평가를 함께 활용해 목적지까지 가장 안전한 길을 안내합니다.

주요 기능

  • 안심 경로 추천 — 안심 점수가 가장 높은 경로 안내
  • 골목·도로 안전도 평가 — 이동한 길을 1~5점으로 평가
  • LLM 위험도 분석 — 사용자 평가와 CCTV·경찰서·가로등 데이터를 LLM이 분석

차별점 & 나의 역할

위험 지점을 ‘표시’만 하는 기존 앱과 달리 안전도를 경로 계산에 직접 반영합니다. 저는 LLM 위험도 분석 기능 개발과 발표를 맡았습니다.

개인 프로젝트 · Python
