# 박채아 — Portfolio

선린인터넷고등학교 정보보호과 박채아의 포트폴리오 사이트입니다.
빌드 도구나 설치 없이 HTML / CSS / JS 파일만으로 동작합니다.

🔗 **https://chaea73.github.io/portfolio/**

## 기능

- 반응형 (PC · 태블릿 · 모바일)
- 라이트 / 다크 테마 전환 (선택값은 브라우저에 저장)
- 스크롤에 따라 현재 섹션이 상단 메뉴에 표시
- 스크롤 시 콘텐츠 등장 애니메이션
- 접근성 대응 (본문 바로가기, 키보드 포커스, `prefers-reduced-motion`)

## 폴더 구조

```
portfolio/
├── index.html            ← 모든 내용이 여기 있습니다
├── assets/
│   ├── css/style.css     ← 색상 · 디자인
│   ├── js/main.js        ← 테마 전환, 메뉴, 애니메이션
│   └── img/              ← 사진을 넣는 곳
├── .nojekyll             ← GitHub Pages 설정용 (지우지 마세요)
└── README.md
```

| 03 | 프로젝트 | ⏳ 비어 있음 |

## 숨겨둔 섹션

아래 두 개는 아직 채울 내용이 없어 **주석으로 감춰둔 상태**입니다.
내용이 생기면 `index.html` 에서 해당 `<section>` 앞뒤의 `<!--` `-->` 를 지우고,
상단 헤더의 링크 주석도 함께 풀어주세요.

- **스킬** — `<section ... id="skills">`
- **독서 & 학습 기록** — `<section ... id="reading">`

`02 이력` 안의 **자격증**, **수상** 블록도 같은 방식으로 주석 처리되어 있습니다.

## 내용 고치기

`index.html` 을 VS Code나 메모장으로 열면 `<!-- ✏️ … -->` 주석이 붙어 있습니다.
그 주변 글자만 바꾸면 됩니다.

| 바꾸고 싶은 것 | 위치 |
|---|---|
| 슬로건 · 소개글 | `히어로` 섹션 |
| 메일 · 연락처 | `히어로` 카드 **와** `04 연락처` (두 군데) |
| 프로필 사진 | `assets/img/profile.jpg` 로 저장하면 자동 반영 |
| 관심 분야 3가지 | `01 소개` |
| 학력 · 활동 | `02 이력` |
| 프로젝트 | `03 프로젝트` |
| 강조 색상 | `assets/css/style.css` 맨 위 `--accent` |

### 프로젝트 추가하기

`03 프로젝트` 섹션에서

1. `<p class="empty"> … </p>` 한 줄을 지우고
2. 바로 아래 `<div class="works"> … </div>` 블록의 주석을 풉니다
3. 제목 · 설명 · 태그 · GitHub 주소를 채웁니다

카드를 늘리려면 `<article class="work"> … </article>` 를 통째로 복사하세요.
썸네일을 넣으려면 `assets/img/` 에 이미지를 저장한 뒤:

```html
<div class="work__thumb" style="background-image:url('assets/img/work1.png')"></div>
```

### 스킬 숙련도

`data-level` 숫자만 바꾸면 점 개수가 자동으로 바뀝니다.

```html
<li data-level="2">Python</li>
<!-- 3 = ●●● 상 / 2 = ●●○ 중 / 1 = ●○○ 하 / 0 = 표시 안 함 -->
```
